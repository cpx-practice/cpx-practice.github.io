    이용 방법

    아무것도 깔려 있지 않은 컴퓨터 기준입니다. 순서대로 하면 15분쯤 걸리고, 연결은 한 번만 하면 됩니다.

    사용 설명서 PDF 내려받기 설치부터 면담·채점·기록판 사용법까지 담은 15쪽 문서입니다. 인쇄해서 옆에 두고 봐도 됩니다.

    Claude 유료 플랜(Pro 이상)이 필요합니다. 무료 플랜 계정으로는 앱이 깔려도 면담 명령이 나타나지 않습니다. 설치 전에 플랜부터 확인하세요. Windows 10(1809) 이상이어야 합니다. macOS 13 이상이어야 합니다.

    1. Claude 앱 설치 — 터미널을 쓰지 않는 방법입니다. claude.com/download 에서 Windows용을 받아 설치하고, 앱을 열어 Claude 계정으로 로그인합니다. Mac용 .dmg 를 받아 Claude를 응용 프로그램 폴더로 끌어다 놓고, 앱을 열어 Claude 계정으로 로그인합니다.
      터미널이 편하다면 
      irm https://claude.ai/install.ps1 | iex
      curl -fsSL https://claude.ai/install.sh | bash

      설치 후 claude 를 입력하면 시작됩니다. 나머지 단계는 똑같습니다.

    2. CPX 플러그인 설치 — Claude 안에서 아래 두 줄을 차례로 입력합니다. 
      /plugin marketplace add raphael4040-ash/cpx-marketplace
      /plugin install cpx@cpx-marketplace

      설치 후 /reload-plugins 를 실행하세요 라는 안내가 나오면 그것도 입력합니다. 안 나오면 넘어가도 됩니다.

    3. 연결 코드 발급
      복사됨

      이 코드는 비밀번호와 같은 힘을 가집니다. 본인 컴퓨터에만 붙여넣고, 남에게 보내거나 채팅·깃허브에 올리지 마세요. 유출된 것 같으면 설정 → 연결 해제로 즉시 무효화하세요.

    4. Claude에 붙여넣기 
      /cpx:pair <위에서 복사한 코드>
    5. 연습 시작 — /cpx:start → 문진 → 진찰 → 평가. 평가가 끝나면 자동으로 여기에 기록됩니다. 주제를 고르려면 /cpx:start 가슴통증 처럼 뒤에 붙이면 됩니다.

    그래도 안 되면 2단계의 두 줄을 다시 실행하세요. 이미 설치돼 있어도 다시 해서 문제되지 않습니다.

    로그인은 되는데 명령어가 하나도 안 보입니다

    터미널은 필수가 아닙니다. 1단계의 앱 설치로 하면 이 문제를 안 만납니다.
