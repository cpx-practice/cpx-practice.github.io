    Claude Code와 연결

    한 번만 해두면 이후 연습 결과가 자동으로 이 계정에 쌓입니다.

    1. 플러그인 설치 — 터미널에서 
      claude plugin marketplace add raphael4040-ash/cpx-marketplace
      그다음 Claude Code 안에서 /plugin install cpx@cpx-marketplace
    2. 연결 코드 발급
      복사됨

      이 코드는 비밀번호와 같은 힘을 가집니다. 본인 컴퓨터에만 붙여넣고, 남에게 보내거나 채팅·깃허브에 올리지 마세요. 유출된 것 같으면 설정 → 연결 해제로 즉시 무효화하세요.

    3. Claude Code에 붙여넣기 
      /cpx:pair <위에서 복사한 코드>
    4. 연습 시작 — 아무 폴더에서나 /cpx:start → 문진 → 진찰 → 평가. 평가가 끝나면 자동으로 여기에 기록됩니다.

    연결 해제

    발급한 연결 코드를 모두 무효화합니다. 연결된 기기의 자동 업로드가 즉시 멈추고, 다시 쓰려면 연결 코드를 새로 만들어 /cpx:pair 를 다시 실행하면 됩니다.

    코드가 실제로 유출됐다면 이것만으로는 부족합니다. 무효화는 업로드 경로만 막을 뿐, 코드에 담긴 로그인 자격 자체는 살아있습니다. 비밀번호를 함께 변경하세요.

    가입 승인제

    끄면 누구든 가입 즉시 이용할 수 있습니다. 켰을 때 이미 승인되지 않은 계정은 아래 목록에서 승인해야 기록을 남길 수 있습니다. 관리자 본인은 항상 예외입니다.
