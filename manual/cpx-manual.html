이 문서를 읽는 사람

의사국가시험 실기(CPX/OSCE)를 준비하며 이 시뮬레이터를 처음 쓰는 사람. 아무것도 설치돼 있지 않은 컴퓨터를 기준으로 씁니다. 2장까지만 따라 하면 첫 면담을 시작할 수 있고, 15분쯤 걸립니다. 3장부터는 필요할 때 찾아보는 부분입니다.

차례

  1. 시작하기 전에무엇이 어떻게 연결돼 있는지, 무엇을 준비해야 하는지
  2. 설치와 연결Claude 앱 · 플러그인 · 기록판 가입 · 연결 코드
  3. 면담 진행하기문진 → 진찰 → 평가. 신호, 예외 케이스, 실전처럼 쓰는 법
  4. 채점표 읽는 법100점 배점의 구성과 등급, 결과에 무엇이 나오고 무엇이 안 나오는지
  5. 기록판 사이트내 기록 · 분석 · Claude · 오류 제보 · 이용 방법 · 설정
  6. 저장되는 것과 개인정보무엇이 언제 어디로 올라가는지, 끄는 방법
  7. 막혔을 때증상별 해결 순서
  8. A. 케이스 58개 전체 목록
  9. B. 명령과 파일 한 장 요약

1시작하기 전에

이 시뮬레이터는 두 개의 프로그램으로 이루어져 있습니다. 하나는 면담을 진행하고 채점하는 쪽, 다른 하나는 그 결과를 쌓아 보여주는 쪽입니다. 둘은 한 번 연결해두면 그다음부터는 알아서 붙어 있습니다.

1.1 전체 그림

구성무엇인가하는 일
CPX 플러그인 Claude Code 안에 설치하는 확장 표준화환자(SP) 역할을 맡아 면담을 진행하고, 평가 신호를 받으면 100점 배점으로 채점합니다.
기록판 (웹사이트) 브라우저로 접속하는 개인 계정 페이지 채점 결과와 면담 전문을 계정에 쌓아두고, 케이스별 · 영역별로 어디가 약한지 보여줍니다.
연결 코드 기록판에서 발급받아 한 번만 붙여넣는 문자열 내 컴퓨터의 채점 결과를 내 계정으로 올려보내는 통로입니다. 연결하지 않으면 아무것도 전송되지 않습니다.

면담이 끝나고 채점이 나오면 그 결과가 자동으로 기록판에 올라갑니다. 따로 저장 버튼을 누르거나 점수를 옮겨 적을 일은 없습니다.

1.2 준비물

항목조건
Claude 유료 플랜Pro 이상. 무료 플랜 계정으로는 앱을 깔아도 면담 명령이 아예 나타나지 않습니다.
운영체제Windows 10 (1809) 이상 또는 macOS 13 이상
기록판 계정이메일과 비밀번호로 직접 가입합니다. 관리자 승인제가 켜져 있으면 승인 후 이용할 수 있습니다.
인터넷면담 자체와 기록 업로드 모두 필요합니다.
가장 흔한 좌절 설치는 다 됐는데 /cpx:start 를 쳐도 아무 일이 없다면 열에 아홉은 무료 플랜입니다. 설치를 시작하기 전에 플랜부터 확인하세요.

1.3 실제 시험과 다른 점

  • 입실 전 안내문(Doorway Information)을 주지 않습니다. 현행 국시원 시험이 그렇기 때문입니다. 나이 · 성별 · 내원 사유를 포함해 전부 문진으로 알아내야 합니다.
  • 채점표는 국시원 공식 채점표를 그대로 옮긴 것이 아니라, 그 형식(항목별 배점 + 환자-의사관계 별도 평가)을 본떠 재구성한 연습용 기준입니다. 점수의 절대값보다 어느 항목을 빠뜨렸는지를 보는 데 쓰세요.
  • 시간 제한이 자동으로 걸리지 않습니다. 실전 감각을 원하면 직접 타이머를 켜세요 (3.7 참고).

2설치와 연결

네 단계입니다. 1 · 2단계는 컴퓨터마다 한 번, 3단계는 사람마다 한 번, 4단계는 컴퓨터마다 한 번입니다. 다른 컴퓨터에서도 연습하려면 그 컴퓨터에서 1 · 2 · 4단계만 다시 하면 됩니다.

1Claude 앱 설치

터미널을 쓰지 않는 방법입니다.

  • Windows — claude.com/download 에서 Windows용을 받아 설치하고, 앱을 열어 Claude 계정으로 로그인합니다.
  • Mac — 같은 주소에서 Mac용 .dmg 를 받아 Claude를 응용 프로그램 폴더로 끌어다 놓고 앱을 열어 로그인합니다.

터미널이 편하다면 아래 한 줄로도 됩니다. 설치 후 claude 를 입력하면 시작되고, 나머지 단계는 똑같습니다.

Windows (PowerShell)   irm https://claude.ai/install.ps1 | iex
Mac / Linux            curl -fsSL https://claude.ai/install.sh | bash
2CPX 플러그인 설치

Claude 안에서 아래 두 줄을 차례로 입력합니다. 첫 줄은 플러그인이 있는 곳을 등록하고, 둘째 줄이 실제 설치입니다.

/plugin marketplace add raphael4040-ash/cpx-marketplace
/plugin install cpx@cpx-marketplace

설치가 끝나고 /reload-plugins 를 실행하세요 라는 안내가 나오면 그것도 입력합니다. 안 나오면 넘어가도 됩니다. 제대로 붙었는지는 / 를 눌렀을 때 목록에 /cpx:start 가 보이는지로 확인합니다.

3기록판 가입

브라우저에서 https://cpx-practice.github.io 에 접속해 회원가입 탭에서 닉네임 · 이메일 · 비밀번호(6자 이상)를 넣습니다.

가입 화면 아래에 문진 대화 전문을 함께 저장할지 고르는 체크박스가 있습니다. 기본은 켜짐이고, 나중에 설정 탭에서 언제든 바꿀 수 있습니다 (6장 참고).

승인제가 켜져 있으면 가입 직후에는 "관리자 승인 대기 중" 화면이 뜹니다. 승인되면 다시 로그인할 필요 없이 그 자리에서 대시보드로 바뀝니다.

4연결 코드 발급과 붙여넣기
  1. 기록판에 로그인 → 이용 방법 탭 → 연결 코드 만들기 버튼
  2. 나타난 긴 문자열을 복사 버튼으로 복사합니다.
  3. Claude 로 돌아와 아래처럼 붙여넣습니다.
/cpx:pair <복사한 코드>

"연결됐습니다" 라는 답이 오면 끝입니다. 코드는 내 컴퓨터의 ~/.cpx/token (Windows는 %USERPROFILE%\.cpx\token) 파일에 저장되고, 그 뒤로는 다시 입력할 일이 없습니다.

연결 코드는 비밀번호와 같습니다 이 코드 하나로 내 계정에 기록을 쓸 수 있습니다. 본인 컴퓨터에만 붙여넣고, 남에게 보내거나 채팅 · 깃허브에 올리지 마세요. 유출된 것 같으면 기록판 설정 → 연결 해제로 즉시 무효화하고 비밀번호도 함께 바꾸세요. 무효화는 업로드 경로만 막을 뿐, 코드에 담긴 로그인 자격 자체는 살아 있기 때문입니다.

2.1 잘 됐는지 확인하는 순서

확인정상이라면
Claude 에서 / 입력목록에 /cpx:start 와 /cpx:pair 가 보입니다
/cpx:start 입력설명 없이 곧바로 환자의 첫 대사가 나옵니다
짧게 문진하고 평가채점표와 점수가 나옵니다
기록판 내 기록 탭 새로고침방금 친 케이스가 한 줄 올라와 있습니다

3면담 진행하기

면담은 문진 → 신체진찰 → 평가의 세 단계로 흐릅니다. 단계 전환은 진찰, 평가 두 단어로만 합니다. 이 두 단어 외에는 전부 실제 진료 대화로 취급됩니다.

3.1 시작

/cpx:start           무작위 케이스로 시작
/cpx:start 가슴통증    주제를 지정해서 시작

명령을 넣는 즉시 환자 역할이 시작됩니다. "준비됐습니다" 같은 안내나 입장 신호를 기다리지 않습니다. 주제 이름은 부록 A의 목록을 쓰면 정확하고, 흉통처럼 흔히 쓰는 다른 이름도 대개 알아듣습니다.

새 케이스를 하려면 /cpx:start 를 다시 입력하면 됩니다. 이전 케이스는 그것으로 끝납니다.

3.2 문진 단계

상대는 환자입니다. 의학 용어나 진단명을 스스로 꺼내지 않고, 열린 질문을 던져도 아는 것을 한꺼번에 쏟아내지 않습니다. 실제 환자처럼 조금씩, 물어본 만큼만 답합니다. 그러니 묻지 않은 정보는 끝까지 나오지 않는다고 생각하고 진행하세요.

  • 사전 안내문이 없으므로 나이 · 성별 · 직업 · 내원 사유부터 직접 확인해야 합니다.
  • 한 번에 여러 가지를 묶어 물으면 환자가 하나만 답합니다. 실제 시험과 같습니다.
  • 환자는 감정과 망설임을 표현합니다. 그 반응에 어떻게 대응하는지도 채점(PPI) 대상입니다.

3.3 신체진찰 단계

진찰 이라고 입력하면 상대가 환자에서 소견을 알려주는 서술자로 바뀝니다. 요청하지 않아도 활력징후를 먼저 알려주고, 그다음부터는 내가 시행한 진찰에 해당하는 소견만 나옵니다.

괄호 자동 전환 촉진 · 청진 · 타진 · 시진 · 혈압측정처럼 분명한 진찰 동작을 괄호 안에 적으면 (예: (우하복부를 촉진한다)) 진찰 을 따로 치지 않아도 그 자리에서 신체진찰 모드로 넘어가고 소견까지 나옵니다. 채점에서도 진찰을 시행한 것으로 인정됩니다. 다만 (웃으며), (잠시 망설인다) 같은 감정 · 표정 지문은 전환 대상이 아닙니다.

진단명은 알려주지 않습니다. "충수돌기염 소견입니다"가 아니라 "우하복부 압통과 반발통이 있습니다"처럼 객관적 소견으로만 나옵니다. 해석은 응시자의 몫입니다.

진찰 을 건너뛰고 바로 평가 로 가도 됩니다. 이 경우 신체진찰 20점은 미실시로 0점 처리됩니다.

3.4 평가 단계

평가 를 입력하면 즉시 역할이 끝나고 채점표가 나옵니다. 채점 중에는 환자로 돌아가지 않으므로, 못 물어본 것이 생각나도 그 케이스는 거기서 종료입니다.

채점 메시지 맨 끝에는 점수를 담은 작은 코드 블록이 하나 붙습니다. 기록판이 그 블록만 읽어 점수를 저장하므로 지우거나 편집하지 마세요. 읽을 필요는 없습니다.

3.6 예외 케이스 두 가지

케이스진행 방식
나쁜 소식 전하기 신체진찰 항목이 없습니다. 진찰 을 넣어도 해당 없다고 안내하며, 채점에서는 신체진찰 20점이 항상 만점 처리됩니다. 면담 자체 — 전달 방식과 환자 반응 대응 — 에 집중하세요.
기본진료술기 3종
(응급처치 · 상처 관리 · 채혈 및 혈관 확보)		 문진 케이스가 아니라 절차 수행이 핵심입니다. 시작하자마자 상황이 제시되고 (예: "환자가 갑자기 쓰러졌습니다") 내가 말하는 조치를 순서대로 판정해줍니다. 진찰 신호가 필요 없고, 채점도 술기의 순서와 정확성 기준으로 별도로 이루어집니다.

3.7 실전처럼 쓰는 법

  • 타이머를 켜고 하세요. 실제 CPX는 한 방에서 대략 10분입니다. 시간 안에 ICE와 safety netting까지 닿는 연습이 점수를 가장 크게 바꿉니다.
  • 채점을 보기 전에 "무엇을 빠뜨렸나"를 스스로 한 줄 적어두고 결과와 비교해보세요.
  • 같은 케이스를 며칠 간격으로 두세 번 반복하세요. 기록판 분석 탭이 그 케이스의 회차별 추이를 따로 보여줍니다 (5.3).
  • 점수가 낮게 나오는 것이 정상입니다. 채점은 관대하지 않게 맞춰져 있고, 수행이 없었으면 잘한 점 항목 자체가 나오지 않습니다.

4채점표 읽는 법

100점 배점이고, 항목마다 O(만점) · △(절반) · X(0점)가 매겨집니다. 섹션 제목에 소계가 붙어 나오므로 어디서 점수가 샜는지 바로 보입니다.

4.1 I. 병력청취 — 60점

묶음배점항목
1. 도입5자기소개와 신분 확인 (2) / 환자 확인 — 이름 · 나이 (1) / 개방형 질문으로 방문 목적 시작 (2)
2. 주호소와 현병력20주호소 명확화 (2) / 발병시기 (2) / 경과 · 양상 (2) / 위치와 방사 (2) / 악화 · 완화 요인 (3) / 강도 0~10 (2) / 동반 증상 (4) / 과거 유사 증상 (3)

4.5 결과에 일부러 넣지 않은 것

채점 결과는 다섯 가지만 나옵니다. 섹션별 항목 채점표, 총점과 등급, 잘한 점, 개선점 2~3가지, 그리고 기록 전달용 코드 블록입니다. 아래는 의도적으로 빼두었습니다.

  • 서두 인사와 상황 설명 — 첫 줄부터 바로 채점표입니다.
  • 총평 한 줄 — 기록판의 총평 칸으로만 남습니다.
  • 수행하지 않은 항목의 "미시행" 코멘트 — X 표시로 이미 드러나기 때문입니다.
  • 근거 없는 칭찬 — 실제 대화에서 관찰된 수행이 없으면 잘한 점 항목 자체가 나오지 않습니다. 태도나 시도를 칭찬으로 채우지 않습니다. 대신 개선점 쪽에 던졌어야 할 질문을 그대로 인용해 보여줍니다.

5기록판 사이트

로그인하면 여섯 개 탭이 나옵니다. 기록은 전부 플러그인이 올리므로 사이트에서 점수를 직접 입력할 일은 없습니다. 사이트는 읽고, 분석하고, 지우는 곳입니다.

5.1 내 기록

지금까지의 면담이 최신순 표로 쌓입니다. 날짜 · 주제 · 총점 · 병력 · 진찰 · PPI · 총평 순입니다.

  • 검색창은 주제와 총평을 함께 훑습니다. 주제, 기간(7 · 30 · 90일), 정렬(최신 / 오래된 / 총점 높은 / 낮은)로 거를 수 있습니다.
  • 한 줄을 누르면 상세 창이 열리고 채점 결과와 문진 전사 두 탭이 있습니다. 전사는 저장에 동의한 경우에만 채워집니다.
  • 상세 창 오른쪽 위 .md 버튼은 제목 · 일시 · 점수 · 채점 결과 · 문진 전사를 담은 마크다운 파일을 바로 내려받습니다.
  • PDF 버튼은 브라우저 인쇄 대화상자를 엽니다. 대상에서 "PDF로 저장"을 고르면 됩니다. 화면에서는 탭으로 갈려 있는 채점 결과와 문진 전사가 인쇄물에는 둘 다 담깁니다.
  • 기록은 수정할 수 없고 삭제만 됩니다. 잘못 올라간 회차는 지우고 다시 하세요.

5.2 분석 — 영역별 성취율

병력청취 · 신체진찰 · PPI 세 영역을 배점 대비 몇 퍼센트로 받고 있는지 막대로 보여줍니다. 총점이 비슷해도 어느 영역에서 잃고 있는지가 여기서 갈립니다. 분석 탭은 내 기록 탭의 필터를 타지 않고 항상 전체 기록으로 그립니다.

5.3 분석 — 케이스별 점수

국시원 48개 임상표현과 기본진료술기 3개를 합한 58개 케이스를 한 줄씩 전부 냅니다. 안 해본 케이스는 "미실시"로 흐리게 남으므로, 이 표 하나가 커버리지 점검표를 겸합니다.

  • 해본 케이스를 누르면 회차별 점수가 펼쳐지고, 회차마다 면담 보기로 그때의 채점 결과와 전사를 볼 수 있습니다. 그 옆 삭제 버튼으로 그 자리에서 지울 수도 있습니다.
  • 오른쪽에는 그 케이스의 성적 추이가 회차별 막대와 "첫 회 58 → 최근 88 (+30)" 형태의 한 줄로 나옵니다. 한 번뿐이면 그렇다고 적힙니다.
  • 검색창을 누르면 58개 케이스 이름이 선택지로 뜹니다. 범위를 전체 / 해본 것만 / 안 해본 것만으로 좁힐 수 있습니다.
  • 표 아래에 "케이스 뱅크에서 이름을 찾지 못한 기록"이 뜨면, 채점 때 주제 이름이 목록과 달라 커버리지에서 빠졌다는 뜻입니다. 오류 제보로 알려주시면 목록을 맞춰 고칩니다.

5.4 Claude

버튼 하나로 Claude 앱을 열고 /cpx:start 를 클립보드에 복사해줍니다. 앱에서 붙여넣기만 하면 바로 면담이 시작됩니다. 아래에는 면담이 어떻게 흘러가는지 세 줄 요약이 있습니다.

5.5 오류 제보

이상한 점을 적어 보내는 곳입니다. 무엇을 하다가 그랬는지 함께 적어주면 원인을 찾기 쉽습니다.

  • 화면을 캡처해 입력칸에 Ctrl+V 로 붙여넣으면 이미지가 바로 첨부됩니다. 파일 선택도 됩니다. 이미지는 보내기 전에 브라우저에서 크기를 줄입니다.
  • 내용과 함께 닉네임 · 이메일, 보고 있던 탭, 브라우저 종류가 전송됩니다. 연락과 재현에만 씁니다.
  • 승인 대기 중에도 제보는 보낼 수 있습니다. 아래에 내가 보낸 제보와 처리 상태가 쌓입니다.

5.6 이용 방법

설치 절차와 연결 코드 발급이 있는 탭입니다. Windows / Mac 전환 버튼이 있어 내 운영체제에 맞는 안내만 볼 수 있습니다. 컴퓨터를 바꿨거나 연결이 끊겼을 때 여기서 코드를 새로 만들면 됩니다.

5.7 설정

항목동작
문진 대화 전문도 저장하기 끄면 이후 업로드부터 대화 내용이 저장되지 않고 점수와 총평만 남습니다. 이미 저장된 전사는 그대로 있으니, 지우려면 해당 기록을 삭제하세요.
모든 연결 코드 무효화 발급한 코드를 전부 못 쓰게 만듭니다. 연결된 기기의 자동 업로드가 즉시 멈춥니다. 다시 쓰려면 코드를 새로 만들어 /cpx:pair 를 다시 실행하면 됩니다.

오른쪽 위 아이콘으로 화면 밝기를 자동 · 밝게 · 어둡게로 돌릴 수 있고, 선택은 브라우저에 기억됩니다.

6저장되는 것과 개인정보

무엇이 언제 전송되는지, 그리고 어디서 끌 수 있는지를 정확히 적어둡니다.

6.1 언제 전송되는가

  • 연결하지 않으면 아무것도 전송되지 않습니다. /cpx:pair 를 한 번도 안 했다면 업로드 기능은 아예 동작하지 않습니다.
  • 연결한 뒤에도 전송은 평가 를 마쳐 채점 결과가 나온 순간에만 일어납니다. 문진 중이나 신체진찰 중에는 네트워크를 타지 않습니다.
  • CPX와 무관한 다른 대화는 이 플러그인을 통해 전송되지 않습니다.

6.2 무엇이 올라가는가

구분내용
항상케이스 주제, 총점과 영역별 점수(병력청취 · 신체진찰 · PPI), 등급, 총평 한 줄, 채점 결과 전문
동의한 경우에만문진 대화 전문. 실제로 오간 면담만 남기고 슬래시 명령, 내부 지시문, 도구 호출, 채점 메시지는 걷어냅니다. 면담이 아주 길면 뒷부분만 저장되고 잘렸다는 표시가 남습니다.
계정 정보닉네임, 이메일, 전사 저장 동의 여부

기록은 본인 계정에서만 보입니다.

6.3 끄는 방법 두 가지

방법차이
내 컴퓨터에서 막기
~/.cpx/config 에 transcript=0		 대화 내용이 아예 전송되지 않습니다. 점수와 총평만 올라갑니다. 파일을 직접 만들기 번거로우면 Claude 에게 "문진 내용은 올리지 마"라고 말하면 대신 만들어줍니다. 되돌리려면 그 파일을 지우거나 transcript=1 로 바꿉니다.
사이트에서 막기
설정 탭의 저장 스위치		 전송은 되지만 서버가 전사를 버립니다. 두 번째 방어선이라고 보면 됩니다.

완전히 남기고 싶지 않다면 두 곳을 모두 끄는 편이 확실합니다.

6.4 연결을 끊고 싶을 때

  • 이 컴퓨터만 끊기 — ~/.cpx/token (Windows는 %USERPROFILE%\.cpx\token) 파일을 지우면 그 즉시 업로드가 멈춥니다.
  • 모든 기기 끊기 — 기록판 설정 탭의 연결 해제. 발급했던 코드가 전부 무효가 됩니다.
  • 코드가 실제로 유출됐다면 무효화만으로는 부족합니다. 비밀번호도 함께 바꾸세요.
알아둘 것 기록은 수정이 막혀 있고 삭제만 됩니다. 계정 삭제 기능은 아직 없으므로, 필요하면 오류 제보로 요청해주세요.

7막혔을 때

/cpx:start 를 쳤는데 아무 일도 안 일어납니다

  1. /reload-plugins 를 입력해봅니다.
  2. 그래도 안 되면 앱을 완전히 껐다 켭니다.
  3. 그래도 안 되면 2단계의 두 줄을 다시 실행합니다. 이미 설치돼 있어도 다시 해서 문제되지 않습니다.

로그인은 되는데 명령어가 하나도 안 보입니다

무료 플랜 계정일 가능성이 큽니다. Claude Code는 Pro 이상에서만 열립니다. 플랜을 확인하세요.

면담은 끝났는데 기록이 안 올라옵니다

  1. 연결이 안 됐거나 코드가 무효화된 경우가 대부분입니다. 이용 방법 탭에서 코드를 새로 만들어 /cpx:pair 를 다시 실행하세요.
  2. 승인제가 켜져 있는데 아직 승인 전이면 올라가지 않습니다. 승인 후 다시 시도하세요.
  3. 채점 메시지 끝의 코드 블록을 지웠거나 채점이 중간에 끊겼다면 그 회차는 올라가지 않습니다. 다시 평가 를 받으세요.

점수는 올라왔는데 문진 전사가 비어 있습니다

전사 저장을 꺼둔 상태입니다. 6.3의 두 곳 — 내 컴퓨터의 config 파일과 사이트 설정 스위치 — 를 확인하세요. 이미 저장된 회차에는 소급 적용되지 않습니다.

설치 명령이 오류가 납니다

Windows에서 'irm' is not recognized 가 나오면 PowerShell이 아니라 CMD 창입니다. 프롬프트가 PS C:\ 로 시작해야 PowerShell입니다. 터미널은 필수가 아니니, 2단계 1번의 앱 설치 방식으로 하면 이 문제를 아예 만나지 않습니다.

가입은 했는데 승인 대기에서 넘어가지 않습니다

관리자가 승인해야 넘어갑니다. 승인되면 다시 로그인할 필요 없이 그 화면이 대시보드로 바뀝니다. 오래 걸리면 오류 제보로 알려주세요. 승인 대기 중에도 제보는 보낼 수 있습니다.

분석 탭에 "이름을 찾지 못한 기록"이 떴습니다

채점 때 적힌 주제 이름이 케이스 목록과 달라 커버리지에서 빠졌다는 표시입니다. 점수 자체는 그대로 저장돼 있습니다. 어떤 이름이 떴는지 오류 제보로 알려주시면 목록에 반영합니다.

그 밖에 뭔가 이상합니다

오류 제보 탭에 적어 보내주세요. 화면을 캡처해 입력칸에 Ctrl+V 로 붙이면 그대로 첨부됩니다. 무엇을 하다가 그랬는지 한 줄만 더 적어주면 훨씬 빨리 찾습니다.
